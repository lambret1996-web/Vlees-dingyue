# 多国家VLESS订阅转换器

为小火箭(Shadowrocket)生成多国家VLESS订阅链接的Web工具，支持一键生成10个主流国家的配置。

## 功能特点

- **多国家支持**：美国、日本、新加坡、德国、英国、韩国、加拿大、法国、澳大利亚、荷兰
- **路径自定义**：自动生成符合格式的WebSocket路径
- **可视化界面**：友好的用户界面，操作简单
- **一键生成**：快速生成订阅链接
- **二维码支持**：扫描二维码直接导入小火箭
- **适配小火箭**：生成符合小火箭格式的VLESS链接

## 部署到Cloudflare Pages

1. Fork此仓库到您的GitHub账户
2. 登录Cloudflare Dashboard
3. 进入Pages → 创建项目 → 连接到Git
4. 选择您的仓库
5. 设置构建配置：
   - 构建命令：无（留空）
   - 构建输出目录：/
6. 点击"保存并部署"

## 使用方法

1. 打开部署的网站
2. 填写UUID（必填）
3. 可选：填写Host/SNI
4. 可选：填写优选IP
5. 选择需要的国家
6. 点击"生成订阅链接"
7. 复制订阅链接或扫描二维码导入小火箭
